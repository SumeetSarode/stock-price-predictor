Prediction Walkthrough · single-file edition

How we make stock predictions

A complete, plain-English walkthrough of the data we read, the indicators we compute, the patterns we hunt for, and the way we combine all of it into a single, time-boxed call for one NSE-listed stock.

No code. No jargon-without-explanation. Aimed at someone who knows technical analysis and the news cycle, but does not read software.

📌 Five-line summary

  1. For one stock at a time, we ask: where is price likely to go over the next 1, 5, 10, and 21 trading days?
  2. We answer with five numbers per horizon: direction, entry zone, target, stop-loss, confidence.
  3. The answer is built from two parallel reads: a technical view (chart math) and a news view (an LLM reading actual headlines & filings).
  4. Both reads are passed to a synthesizer that weighs them differently per horizon (news matters more daily, trend matters more monthly) and writes the final prediction.
  5. Before shipping, every prediction passes four guardrail checks (grounding, citation, consistency, calibration). One retry, then abort.

The two-phase pipeline at a glance

Same indicators, same news read, same RSI value — fed into four parallel synthesizer calls that each produce one horizon's prediction. The synthesizer is the same LLM each time; only the prompt's horizon label, the per-horizon weights, and the per-horizon ATR bands change.

1 · Data we ingest

Price bars (OHLCV, daily)

For one ticker we fetch about two calendar years of daily bars (≈ 520 trading sessions). Each bar carries the five numbers every chartist knows:

FieldMeaning
OpenFirst traded price of the session (NSE: 09:15 IST).
HighHighest price touched during the session.
LowLowest price touched during the session.
CloseFinal traded price (NSE: 15:30 IST).
VolumeTotal number of shares traded.

Fallback chain (resilient fetcher)

  1. yfinance — primary. Yahoo Finance's free OHLCV feed.
  2. Stooq — fallback. Polish data provider that mirrors most global tickers.
  3. Alpha Vantage — final fallback. Requires an API key.
If a provider fails transiently, it's marked asleep for 60 seconds and we move to the next. If every provider has failed recently, we drop the cooldown and try them all anyway — better to risk a duplicate rate-limit call than to deny the user an answer.

Why two years of bars?

Several indicators need long history before their math stabilises. The biggest offender is ADX: it's doubly smoothed by Wilder's averaging, which means the starting bias only decays below 1% after about 10 × length = 140 bars. Add the 200-bar SMA and a 60-bar squeeze lookback and you need roughly 400 trading days before every number on the page is meaningful. 520 gives comfortable headroom.

News headlines (GDELT)

The Global Database of Events, Language and Tone — a non-profit project that indexes news media worldwide in near-real-time. We query its Doc API 2.0 endpoint (rolling 7-day index).

What we keepWhat we drop
Title, URL, published timestamp (converted to IST), source domain, language. GDELT's pre-computed tone score and themes taxonomy — we let the LLM read the article itself instead of trusting a third-party sentiment guess.

Two-step fetch

  1. Discovery (fetch_news): ask GDELT for all articles about ticker X in the last 1–7 days. Get back metadata only.
  2. Extraction (fetch_article_body): for the headlines the LLM decides are material, fetch the URL and extract clean text using trafilatura (strips ads, nav, related-article rails).
Extraction failure is normal at scale (paywalls, JS-only sites, bot blocks). We surface those as status=error data rather than throwing exceptions.

Language: English-only by default. A leak in a vernacular Indian paper may move HDFCBANK 2% intraday and we never see it. Phase-2 backlog.

NSE corporate filings

The same "Corporate Information → Announcements" feed that powers NSE's website. Sources:

  • Insider trades — promoter buys/sells, often a leading indicator.
  • Board-meeting notices — typically 7–14 days before earnings.
  • Result publications — the actual quarterly numbers when they drop.
  • Regulatory disclosures — SEBI inquiries, related-party transactions.
⚠️ Fragility note. This is not a public API. We prime cookies, forge browser headers, and handle Cloudflare challenges. NSE can (and does) silently change the contract — when they do, this layer goes down until someone notices and patches it.

Analyst estimates

Pulled from yfinance's analyst snapshot. Per ticker we keep EPS/revenue forecasts (current quarter, next quarter, current year, next year), recommendation counts (Strong-Buy / Buy / Hold / Sell / Strong-Sell), and price-target distribution (low / median / mean / high).

The news LLM uses estimates as the expectations baseline. A 5% EPS growth is bullish if estimates expected 3%, but bearish if estimates expected 12%. Without estimates, the LLM has no way to interpret "beat" or "miss".

India VIX (market regime)

NSE's implied-volatility "fear gauge" — one free daily number for expected 30-day volatility, fetched via yfinance (^INDIAVIX). Used as a regime gate, never a direction signal: high-vol → smaller size / wider stops; low-vol → cleaner setups. Self-calibrating against its own rolling median (>1.15× = high_vol, <0.85× = low_vol).

Point-in-time news (Wayback Machine)

Used only during honest backtests. The Internet Archive's CDX API returns the most recent snapshot at/before the as_of date, extracted with trafilatura. Hard guarantee: we never return a snapshot captured after as_of, and we never fall back to the live page — that would reintroduce look-ahead bias. No snapshot → the observation is dropped.

What happens when a source fails

If this fails…We do this
Price bars (all three providers)Abort the prediction. No technicals = no anchor.
News (GDELT down or empty)Degrade gracefully. Synthesize a "neutral, confidence=0, no catalysts" placeholder and tag the prediction with news_impact:degraded.
FilingsSurface as "no filings considered". News LLM continues with what it has.
EstimatesSurface as missing. News LLM continues but cannot do beat-vs-miss framing.

2 · Trend cluster

Simple Moving Average (SMA)

The plain average of the last N closing prices.

SMAN = (closet + closet−1 + … + closet−N+1) / N

We compute three lengths: 20, 50, 200 — short, medium, long-term gauges (Murphy 1999).

The SMA stack

Per SMA we record "is close above this SMA?" and "% distance to it". The stack score is the count of SMAs the close is above (0–3):

ScoreMeaningTag
3Above all three SMAs — full bullish alignment.Bullish lean
2Above two; usually below the slowest one.Bullish lean
1Below two; only the fastest holds.Bearish lean
0Below all three.Bearish lean
TCS close ₹3,820. SMA20 = 3,780, SMA50 = 3,690, SMA200 = 3,560. Close above all three → stack = 3 → bullish lean. The next gate (ADX) decides whether that lean becomes a real verdict.

Exponential Moving Average (EMA-20)

Same idea as SMA, but recent bars get more weight.

EMAt = α × closet + (1 − α) × EMAt−1, α = 2 / (N + 1)

Length: 20 (Pring 2002). Faster than SMA — strength is early signal, weakness is more whipsaws.

ADX and the Directional Indicators (Wilder 1978)

The ADX answers a different question than the SMAs: not where the trend is, but how strong it is. +DI and −DI tell you whether buyers or sellers have been in control.

ValueWhat it means
ADX < 20No trend Price meandering. Treat any other signal with extra caution.
ADX 20–25Grey zone (StockCharts convention). Weak trend.
ADX 25–40Strong trend — Wilder's original 25 threshold.
ADX 40+Very strong. Often near exhaustion.
We use ADX as a strength gate. If ADX is below 20, the trend cluster's verdict is forced to neutral regardless of how bullish the SMA stack looks. A "bullish alignment in a directionless market" is just chop pretending to be a trend.

Convergence guard: ADX is doubly Wilder-smoothed; we refuse to publish it until 140 bars exist, because an undercooked ADX value would mislead the gate.

Ichimoku Cloud (Hosoda 1969)

A five-line "one glance" system on the canonical daily (9, 26, 52, 26) parameters.

Tenkan-sen (9) = (9-bar high + 9-bar low) / 2
Kijun-sen (26) = (26-bar high + 26-bar low) / 2
Senkou Span A = (Tenkan + Kijun) / 2, plotted 26 bars ahead
Senkou Span B = (52-bar high + 52-bar low) / 2, plotted 26 bars ahead
Chikou Span = close, plotted 26 bars behind

The band between Senkou A and B is the cloud (kumo). Three signals: price vs. cloud (above = bullish regime, below = bearish, inside = no-man's-land), Tenkan/Kijun cross, and the forward kumo twist.

Role: Ichimoku casts no deterministic vote — it is surfaced as structured data for the LLM to weigh, a regime snapshot rather than a hard gate. (Hosoda 1969; Patel, Wiley 2010.)

3 · Momentum cluster

Relative Strength Index (RSI-14)

Wilder's classic. Ratio of up-moves to down-moves over 14 bars, normalised to 0–100.

RSI = 100 − 100 / (1 + RS), RS = avg gain / avg loss over N bars
ReadingWilder's classicTrend-RSI (Cardwell/Brown)
> 70OverboughtStill bullish in an uptrend.
60–70Strong, not overbought.+1 bull vote
40–60Neutral middle ground.No vote.
30–40Weak.+1 bear vote
< 30OversoldStill bearish in a downtrend.
We use the 60/40 trend-RSI cuts for voting, not the 70/30 overbought/oversold flags. In an uptrend RSI oscillates 40–80 — using ">70 = bearish" in a strong uptrend would mean fading every push. 70/30 flags are still reported as regime labels.

MACD (Appel, late 1970s)

MACD line = EMA12(close) − EMA26(close)
Signal line = EMA9(MACD line)
Histogram = MACD line − Signal line
SignalDetection ruleVote
Bullish MACD crossHistogram flips from ≤ 0 to > 0.+1 bull
Bearish MACD crossHistogram flips from ≥ 0 to < 0.+1 bear
MACD > Signal (no fresh cross)Still above; consistent positive momentum.+0.5 matching direction

Stochastic Oscillator (Lane, 1950s)

Where today's close sits inside the recent range. 0 = at the lowest low, 100 = at the highest high.

%K = (close − lowN) / (highN − lowN) × 100, N = 14
%K then smoothed over 3 bars (slow %K). %D = 3-bar SMA of slow %K.
ConditionVote
%K > %D AND both above 50+0.5 bull
%K < %D AND both below 50+0.5 bear
%K > 80 / < 20Overbought / oversold flag (no vote flip; reported as label).

On-Balance Volume (Granville 1963)

Running cumulative sum: add today's volume if close went up, subtract if down, ignore if flat.

OBVt = OBVt−1 + (sign of close change) × volumet

Absolute level is meaningless — only the slope matters. We compute the 20-bar slope:

OBV slope (20) = (OBVtoday − OBV20 bars ago) / |OBV20 bars ago| × 100
Positive slope → +0.5 bull. Volume confirming price. Negative slope → +0.5 bear.

How the momentum vote becomes a verdict

Sum all four contributions (RSI ±1, MACD ±1 or ±0.5, Stoch ±0.5, OBV ±0.5). Signed total becomes the verdict; min(|net| / 3, 0.85) becomes the classifier's confidence. Maximally aligned momentum caps at ~0.83 — we never claim near-certainty from indicators alone.

4 · Volatility cluster

Average True Range (ATR-14) — the most important number

The single most important number in the whole system. ATR is the unit in which every stop and target is expressed.

True Ranget = max(high − low, |high − prev close|, |low − prev close|)
ATRt = Wilder smoothing of True Range over 14 bars

The second and third terms handle gap risk: a stock that gaps open above yesterday's high has a true range bigger than its intraday spread.

RELIANCE close ₹2,900 with ATR ₹40. Typical daily swing ≈ 1.4% of price. A 2 × ATR stop sits ₹80 away (~2.8%). That's the unit we use for every risk decision in this stock.

Bollinger Bands (Bollinger, early 1980s)

Middle = SMA(close, 20)
Upper = Middle + 2 × stdev(close, 20)
Lower = Middle − 2 × stdev(close, 20)

%B — location of close inside the band

%B = (close − lower) / (upper − lower)
%BPositionVote
> 1.0Above upper band (breakout)Bullish
0.55 – 1.0Upper halfBullish lean
0.45 – 0.55MiddleNeutral
0 – 0.45Lower halfBearish lean
< 0Below lower bandBearish

Bandwidth

bandwidth % = (upper − lower) / middle × 100

Two distinct squeezes (do not conflate)

Bollinger bandwidth squeeze
"Bands are quieter than usual"

Bandwidth in the lowest 20% of values over the past 60 bars (Bollinger 2001, ch. 11). Diagnostic only — surfaced in rationale, no vote.

TTM Squeeze (Carter 2009) ⚡
"Spring is coiled"

Stricter AND-gate: upper Bollinger band sits inside the upper Keltner channel AND lower BB inside lower KC. Actionable — when TTM fires, strength escalates to strong.

The volatility classifier emits three fields

5 · Levels cluster

Levels are price points, not scores. They anchor target and stop placement.

Swing high / swing low

The highest high and lowest low over the last 30 bars (≈ 6 weeks). Most recent actionable resistance / support.

52-week high / low

Highest high and lowest low over 252 trading days. Psychological levels every retail trader watches.

Classic floor-trader pivots

Pivot Point (PP) = (high + low + close) / 3
R1 = 2 × PP − low (first resistance)
S1 = 2 × PP − high (first support)
R2 = PP + (high − low)
S2 = PP − (high − low)
R3 = high + 2 × (PP − low)
S3 = low − 2 × (high − PP)

VWAP — rolling and anchored

Typical price (TP) = (high + low + close) / 3
Rolling VWAP (20) = Σ(TP × vol, last 20 bars) / Σ(vol, last 20 bars)
Anchored VWAP = Σ(TP × vol, from anchor date) / Σ(vol, from anchor)
VWAP acts as a dynamic support/resistance line. Institutional desks target VWAP for fills, so when price pulls back to VWAP in an uptrend it often attracts buying. The anchored variant pins VWAP to a specific catalyst day (Budget, post-earnings gap, RBI policy).

The levels classifier verdict

Find the nearest level in ATR units (regime-adjusted), then:

  • Within 0.5 ATR above nearest support → Bullish (holding support).
  • Within 0.5 ATR below nearest resistance → Bearish (capped at resistance).
  • No level within 0.5 ATR → Neutral (mid-range).
HDFCBANK close ₹1,650 with ATR ₹22. Swing-low support at ₹1,640. Distance = ₹10 = 0.45 × ATR → bullish lean, confidence ~0.6.

6 · Crossovers — Golden, Death, EMA, MACD

Probably the most-asked-about set of signals in retail TA. We detect them rigorously, vote them conservatively, and report them honestly — including when nothing has happened.

What we report for every crossover pair

For each pair (e.g. SMA-50/200) we emit a five-field record on every bar — not just a yes/no when an event fires:

FieldWhat it tells you
currentIs the short MA currently above or below the long MA? The "regime".
last_eventThe last time these two MAs crossed — was it bullish or bearish?
bars_since_eventHow many trading days ago. (3 = fresh, 47 = stale, 750 = ancient.)
short_ma / long_maLatest values — useful for "how close to a cross?"
Why all five fields and not just "cross today: yes/no"? Because a simple yes/no returns "no" 99% of the time — uninformative — and invites the LLM to infer a cross from the SMA stack alone (which is wrong). With this richer report the agent always has something true to say.

Golden Cross and Death Cross (SMA-50 / SMA-200)

NameDefinitionImplied bias
Golden CrossSMA-50 crosses above SMA-200 on the latest bar.Bullish regime change
Death CrossSMA-50 crosses below SMA-200 on the latest bar.Bearish regime change
Day before yesterday SMA-50 = 1,802, SMA-200 = 1,810 (short below long). Yesterday SMA-50 = 1,808, SMA-200 = 1,809 (still below). Today SMA-50 = 1,815, SMA-200 = 1,810 (short now above). Today's sign flip = Golden Cross with bars_since_event = 0.

Only the canonical SMA-50/200 pair earns the marketing name in agent prose. EMA-9/21 and custom pairs get generic phrasing like "bullish EMA-9/21 cross".

⚠️ How much does the Golden Cross actually predict?

The crossover signal is famous, but the academic record on its alpha has weakened sharply on liquid large-caps. Three published studies you can look up:

StudyFinding
Brock, Lakonishok & LeBaron (1992), J. Finance 47(5) Dow 1897–1986, 50/200 SMA crossover gave statistically significant ~0.045% per buy-day excess return. Excluded transaction costs.
Sullivan, Timmermann & White (1999), J. Finance 54(5) Re-tested BLL using White's Reality Check across 7,846 trading rules. 50/200 edge does not replicate out-of-sample (1987–1996).
Zakamulin (2014), J. Asset Management 50/200 SMA-crossover Sharpe drops from ~0.6 pre-1970 to ~0.1 post-1990 on US equity indices.
Honest takeaway. We ship the Golden / Death Cross primarily as a truth-telling, user-expectation feature — users ask the agent about it, the agent should answer accurately. It is not a high-conviction directional signal on its own.

How crossovers vote

The trend cluster's verdict is built from SMA stack → ADX gate → DI confirmation. The crossover then acts as a nudge: it can push a neutral base verdict to bullish or bearish, but it cannot override a verdict already locked in by the stack + DI.

  • Only fresh crosses vote (bars_since_event ≤ 5). Stale crosses are reported but don't vote.
  • Vote weights: SMA-50/200 fresh cross = ±0.5; EMA-9/21 fresh cross = ±0.3 (faster pair = more whipsaws).
  • Net vote magnitude must be ≥ 0.5 to nudge.
  • DI direction vetoes conflicting nudges (a bullish cross won't nudge bullish if −DI > +DI).

Conflict by design

When the two pairs disagree (SMA-50/200 bullish + EMA-9/21 bearish):

net vote = +0.5 + (−0.3) = +0.2 → below 0.5 threshold → no nudge.
That's the right answer. SMA-bullish-but-EMA-bearish is the textbook fingerprint of a pullback within an uptrend. The agent reports both events but the verdict stays neutral, which protects against whipsaw entries.

The MACD cross (momentum cluster)

Same idea as MA crosses, but on the MACD histogram. Detection rules:

  • Histogram ≤ 0 yesterday, > 0 today → Bullish cross +1
  • Histogram ≥ 0 yesterday, < 0 today → Bearish cross +1
  • No fresh cross but MACD > Signal → +0.5 bull (momentum still positive)
  • No fresh cross but MACD < Signal → +0.5 bear

EMA-9/21 — the swing trader's faster cousin

Same stock, same period. SMA-50 might cross above SMA-200 in early February. The EMA-9 typically crossed above EMA-21 in late November — three months earlier. EMA cross caught the early move; SMA cross confirmed the regime. Both useful, different reasons.

The EMA pair carries half the vote weight (±0.3 vs. ±0.5) precisely because it whips around more.

8 · Chart patterns — the five LMW shapes

Unlike candlesticks, chart patterns span many bars and capture structural price action. Our five pairs come from Lo, Mamaysky & Wang (2000), "Foundations of Technical Analysis", Journal of Finance 55(4).

Pivot detection (and how we deviate from LMW)

Every chart pattern is built on swing pivots. We use scipy.signal.find_peaks with a minimum separation of 5 bars.

Honest deviation. The LMW paper uses a Nadaraya–Watson kernel smoother to identify pivots. We use peak-finding on raw bars instead — cheaper compute, no bandwidth knob, but more sensitivity to single-bar wicks. The geometric tolerances (1.5%, 0.75%, 22-bar) are still LMW's.

Confidence floor: any detected pattern with confidence < 0.7 is dropped silently.

Double top & double bottom

Geometric definition (LMW Def. 5)

  • Two consecutive swing highs (or lows) within 1.5% of their average.
  • At least 22 trading days apart.
  • A real trough (or peak) must exist between the two extremes.

Confidence + target

confidence = peak_similarity × depth_score
depth_score = min(trough_drop_pct / 5%, 1.0)

Double top target = neckline − (resistance − neckline)
Double bottom target = neckline + (neckline − support)
Two peaks at ₹1,510 and ₹1,498 (avg ₹1,504). Trough at ₹1,420 (5.6% drop). Confidence ≈ 0.96 × 1.0 = 0.96. Target on neckline break = 1,420 − (1,504 − 1,420) = ₹1,336.

Head & Shoulders + Inverse H&S

  • Three consecutive swing highs where the middle (head) is taller than the two shoulders.
  • Shoulders within 1.5% of their average.
  • Two neckline troughs within 1.5% of their average.
  • Head ≥ 3% above the higher shoulder (prominence requirement).
confidence = shoulder_similarity × prominence_score × neckline_similarity

H&S target = neckline − (head − neckline)
Inverse H&S target = neckline + (neckline − head)

Ascending (bullish)
Descending (bearish)
Symmetric (neutral)

Fit least-squares lines through the last 5 swing highs (upper) and 5 swing lows (lower):

TypeUpper lineLower line
AscendingFlat (≤ 0.75% spread)Rising
DescendingFallingFlat
SymmetricFallingRising

"Flat" (LMW Def. 4) = spread between highest and lowest pivot on that trendline ≤ 0.75% of their mean.

Broadening tops / bottoms (megaphone)

The mirror of a triangle: upper line rises, lower line falls. Pivots getting more extreme over time, not converging.

Broadening indicates rising volatility and emotional trading — often seen near market tops in retail-heavy stocks. Edwards & Magee treat them as bearish-biased reversal signals when they appear in an uptrend.

Rectangles (sideways consolidation)

Both upper and lower trendlines flat (≤ 0.75% spread). Price oscillates between fixed support and fixed resistance. Continuation-or-reversal — direction undetermined until breakout.

What we deliberately don't implement

  • Cup & handle, flags, pennants, wedges — no closed-form geometric definitions with published tolerances; Bulkowski reports < 50% reliability on flags/pennants.
  • Elliott waves, harmonic patterns (Gartley/Bat/Butterfly) — require human pattern-completion judgement.
  • Fibonacci retracements — require an anchor-point decision; Phase-2 backlog.

Rules the news agent's prompt enforces

1. Materiality filter

2. Already-priced-in adjustment

Story: "Reliance ₹75,000-cr capex." Published 8 days ago; stock already up 9%. Verdict: bullish, but mark importance LOW and add "already absorbed in last week's rally".

3. Expectation framing

Earnings compared against analyst-estimate consensus, not against prior period.

EPS ₹28.40 — 5% growth YoY. Bearish if estimates expected 12%. Bullish if estimates expected 3%. Same number, opposite read.

4. Catalyst quota

  • At most 5 catalysts AND at most 5 risks.
  • If direction = bullish/bearish, at least one catalyst must be present, else NEUTRAL.

  • Every catalyst/risk MUST quote a specific fetched URL.
  • Zero articles → force neutral, magnitude=low, confidence=0.0 with explicit empty-result summary.

10 · The synthesizer — how a prediction is actually written

The synthesizer is the LLM that turns four cluster verdicts + news assessment into one Prediction. Runs once per horizon in parallel.

What the synthesizer sees

  • The TechnicalView: four cluster verdicts + raw numbers.
  • The ImpactAssessment: direction, magnitude, confidence, up to 5 catalysts and risks.
  • The horizon label: DAILY / WEEKLY / BIWEEKLY / MONTHLY.
  • The close price (anchors math).
  • The ATR (unit of stop/target distances).

What it deliberately does NOT see

  • The previous prediction for the same ticker (each call independent).
  • Any backtest outcome from past predictions (no feedback loop).
  • The other horizons' outputs (they may disagree — that's information).

Technicals vs news: qualitative, not weighted

The synthesizer is an LLM agent, not a formula. It applies no fixed numeric weights; the horizon only decides the tie-break when technicals and news disagree.

HorizonWhen tech and news disagree
DAILY / WEEKLYLean technical — price action wins near-term.
BIWEEKLY / MONTHLYLean news — catalysts dominate over multi-week windows.
Sharp disagreementPrefer NEUTRAL rather than picking a side.

Direction call (no fixed formula)

The LLM weighs the four cluster verdicts (each with its own confidence) plus the news direction and calls BULLISH / BEARISH / NEUTRAL. It must name the contributing clusters, surface any dissenting cluster as a conflicting signal, may not go bullish when 3 of 4 clusters are bearish and news is neutral, and treats NEUTRAL as a valid honest answer.

Entry zone placement

HorizonHalf-widthExample at ₹1,000
DAILY±0.5%[₹995.00, ₹1,005.00]
WEEKLY±1.0%[₹990.00, ₹1,010.00]
BIWEEKLY±1.5%[₹985.00, ₹1,015.00]
MONTHLY±2.0%[₹980.00, ₹1,020.00]

Target placement (priority order)

  1. Nearest level beyond the entry zone in predicted direction (swing-high, R1, R2, 52w-high for bullish). Rationale: "target=1605 — anchored to swing-high resistance".
  2. If no such level within 4×ATR, use pure ATR-based target inside the horizon's allowed band.
  3. State the rationale explicitly in either case.

Stop placement

  1. Nearest level on the OPPOSITE side of entry. Verify it's inside the horizon's stop ATR band; if too tight push to stop_min × ATR; if too wide downgrade to NEUTRAL.
  2. If no opposite-side level, use pure ATR stop at midpoint of the horizon's stop band.

Risk-reward floor (1.5×)

If worst-fill RR < 1.5: first try tightening the stop (within band). Otherwise switch to NEUTRAL. Forbidden: inflating the target to force RR ≥ 1.5.

Final confidence math

The LLM picks the confidence itself, anchored to an honesty band — STRONG (near the cap), CLEAR (upper-middle), LEAN (~0.55–0.65), CONFLICT (0.30–0.50 → prefer NEUTRAL), GUESS (0.15–0.30 → NEUTRAL) — then the per-horizon ceiling hard-caps it:

  1. Anchor to the band that matches the evidence (agreement strength, catalyst clarity).
  2. Hard-cap at the horizon ceiling: 0.90 daily / 0.85 weekly / 0.80 biweekly / 0.75 monthly.
A "STRONG" monthly call still tops out at 0.75, not 0.85. Grading is on calibration — confidence matching the realized outcome — not on sounding confident.

When the synthesizer emits NEUTRAL

NEUTRAL is the honest escape hatch. Required when any of:

  • Technicals and news sharply disagree.
  • RR floor of 1.5× cannot be met with any sane stop.
  • Price is mid-range — no nearby support OR resistance within 2 × ATR.
  • Volatility regime is "expanding" AND no clear directional catalyst.

NEUTRAL predictions still emit entry/target/stop, but they describe an expected range. RR set to exactly 1.0 by convention.

Citation & forbidden vocabulary

Every claim must trace to either the TechnicalView signals or the ImpactAssessment catalysts/risks. Rationale cannot contain:

guarantee, certain, definitely, risk-free, easy money, multibagger

Output is educational, not advice — not_advice=True, is_educational=True always.

11 · Horizons, ATR units, risk-reward math

The four horizons

HorizonTrading daysWhat it means
DAILY1Next-session close (today's close if before 15:30 IST).
WEEKLY5+7 calendar days, snapped back to last trading day.
BIWEEKLY10+14 calendar days, snapped back.
MONTHLY21+1 calendar month, snapped back.
Trading-day counts match the user mental model ("monthly = ~21 trading days"); calendar-day snap-back guarantees we never silently extend past a long weekend or Diwali.

Why ATR is the unit of everything

A 1% move means different things in different stocks. In sleepy HUL (ATR ~0.9%) 1% is significant; in volatile Vodafone-Idea (ATR ~5%) it's noise. So we express every stop and every target as a multiple of the stock's own ATR.

RELIANCE close ₹2,900 with ATR ₹40. A 2 × ATR stop sits ₹80 below (≈2.8%). A 1.5 × ATR target sits ₹60 above (≈2.1%). The same 2×ATR stop applied to TCS gives a different percent of price.

Per-horizon ATR bands (source of truth)

HorizonStop (× ATR)Target (× ATR)Entry (± % close)Conf. ceiling
DAILY0.5 – 1.00.75 – 1.5±0.5%0.90
WEEKLY0.7 – 1.51.0 – 2.0±1.0%0.85
BIWEEKLY1.0 – 2.01.5 – 3.0±1.5%0.80
MONTHLY1.5 – 2.52.0 – 4.0±2.0%0.75

Anchors: Wilder's (1978) canonical 1×ATR "swing stop" sits in the WEEKLY band. Van Tharp's (2007) 2–3×ATR positional sits in MONTHLY. Target midpoint ≈ 1.4× stop midpoint per Murphy/Pring/Tharp consensus on positive expectancy.

Risk-reward — two flavours

1. risk_reward — worst-fill anchor (sizing metric)

BULLISH: risk_reward = (target − zone_high) / (zone_high − stop)
BEARISH: risk_reward = (zone_low − target) / (stop − zone_low)

Conservative — the "what if I got the worst possible fill inside the entry band" answer. Guardrail enforces ≥ 1.5.

2. midpoint_rr — textbook (literature-comparison)

entry_mid = (zone_low + zone_high) / 2
midpoint_rr = (target − entry_mid) / (entry_mid − stop) for bullish

Used by Bulkowski's pattern catalogues, Edwards & Magee, every broker's RR calculator. Surfaced for comparability, not used for sizing.

For any zone of nonzero width midpoint_rr ≥ risk_reward.

Grading thresholds (what counts as "right")

HorizonBarsWin thresholdLoss thresholdNeutral cone
DAILY1+0.5%−0.5%±0.5%
WEEKLY5+1.5%−1.5%±1.5%
BIWEEKLY10+2.5%−2.5%±2.5%
MONTHLY21+5.0%−5.0%±5.0%
Thresholds follow roughly √(bars) × 0.5% — the random-walk scaling of price moves with time. We set the bar slightly above the expected stdev so we're only counting genuine directional moves.

Three grading modes

ModeQuestion answered
A — strict directionalDid the realized close-to-close return meet the horizon's win/loss threshold?
B — target/stop resolutionWalking bars, which did price touch first? TARGET_HIT, STOP_HIT, STOP_HIT_AMBIGUOUS (both same bar; counted as stop), or OPEN (neither by deadline).
C — neutral coneFor NEUTRAL only: did realized return stay inside the cone?

Calibration metric: Brier score

Brier = mean((confidence − outcome)²)
outcome = 1.0 if Mode-A correct, else 0.0

Lower is better. Naive baseline (always 0.5 on 50/50 outcome) is 0.25. Below 0.20 = "decent", below 0.15 = "good". We also report Brier skill score (BSS) for apples-to-apples comparison when base rate isn't 50%.

12 · Quality controls — the four guardrail tiers

The synthesizer is an LLM and will occasionally produce predictions that are wrong in mechanical ways: levels in the wrong order, signals it didn't actually see, RR violations, miscalibrated confidence. The guardrail layer catches these deterministically.

How the pipeline works

  • Four tiers run in order; first failing tier short-circuits the rest.
  • On failure, synthesizer is invoked once more with failure messages appended.
  • If retry also fails, the prediction call hard-aborts. No "partial / half-correct" predictions ship.
  • We don't re-run the gather phase on retry (inputs haven't changed).

Tier 1 — Grounding

"Are the prediction's basic numbers internally consistent with their inputs?"

CheckRule
Close-price echoQuoted close = technical-view close to within 0.01%.
Bars-used echoEqual to what was delivered.
Entry-zone width≤ 0.5 × ATR.
Entry-zone touches closeclose ∈ [zone_low − 0.10·ATR, zone_high + 0.10·ATR].
Direction-level sanityBULLISH: target > zone_high AND stop < zone_high.
BEARISH: target < zone_low AND stop > zone_low.
ATR-distance for stopStop distance ∈ [0.5 × ATR, 3.0 × ATR].
NEUTRAL claims neutralityNEUTRAL → RR exactly 1.0.

Tier 2 — Citation

"Did the LLM cite signals it actually saw — or did it make them up?"

We build the allowed vocabulary from: every cluster signal string, every candlestick/chart pattern name, every catalyst/risk title and URL, plus standard indicator names (RSI, MACD, ADX, ATR, BB, %B, OBV, SMA, EMA, +DI, −DI, %K, %D).

CheckRule
Rationale token grounding≥ 80% of meaningful tokens must trace to vocabulary.
contributing_signals matchSubstring match a vocab phrase OR ≥ 70% token overlap.
conflicting_signals matchSame rule.
Catalyst URL anchoringAny cited URL must appear in the news catalysts/risks.
Forbidden vocabularyNone of: guarantee, certain, definitely, risk-free, easy money, multibagger.

Tier 3 — Consistency

"Does the prediction internally hang together?"

CheckRule
Direction ↔ rationaleBULLISH rationale must mention at least one of: up, rise, rally, breakout, buy, long, support holding, momentum positive, trend up. Mirror for BEARISH and NEUTRAL.
Confidence ↔ disagreementMore conflicting than contributing signals → confidence ≤ 0.55.
Confidence ↔ news magnitudeNews HIGH + conf ≥ 0.70 + direction agrees → synthesizer conf ≥ 0.55.
NEUTRAL when split2+ clusters bull AND 2+ bear AND news disagrees → must be NEUTRAL.
NEUTRAL claims no edgeNEUTRAL cannot use "buy/sell/long/short".

Tier 4 — Calibration

"Is the confidence reasonable given the prediction's structure?"

CheckRule
Horizon ceilingconf ≤ 0.90 daily / 0.85 weekly / 0.80 biweekly / 0.75 monthly.
Risk-reward floorrisk_reward ≥ 1.5 (non-NEUTRAL).
NEUTRAL ceilingNEUTRAL → conf ≤ 0.65.
Fallback target penaltyIf rationale mentions "ATR projection", conf ≤ 0.70.
News-boundedDAILY: conf ≤ news_conf + 0.10. WEEKLY: + 0.15.
Degraded news capnews_impact:degraded tag → conf ≤ 0.65.
Why one retry, not many. Empirically, when first attempt violates a guardrail, the second attempt with the failure messages in prompt usually succeeds. Beyond one retry we've seen diminishing returns and the LLM playing whack-a-mole with rules rather than re-thinking. One retry is the cost-vs-quality sweet spot.

14 · Glossary — alphabetical

ADX (Average Directional Index)
Wilder's measure of trend strength (not direction). 0–100. < 20 = no trend; 25+ = strong. Doubly smoothed — needs 140 bars.
Anchored VWAP
Cumulative VWAP from a chosen anchor date forward (Brian Shannon, 2023). Useful around catalysts.
ATR (Average True Range)
Wilder 1978. Smoothed avg of True Range over 14 bars. Our universal unit for stop/target distances.
Bars
Daily OHLCV candles. The smallest time unit we use.
Bollinger Bands
Middle = SMA-20. Upper/lower = middle ± 2 × stdev. John Bollinger, early 1980s.
Brier score
Calibration metric. Mean squared error of (confidence − outcome). Lower better; 0.25 baseline.
Brier skill score
1 − (model Brier / baseline Brier). Positive = beats the naive baseline; 0 = no skill; negative = worse than guessing.

Material news/filing supporting the predicted direction. Carries title, URL, importance, why_it_matters.

SMA-50 crossing below SMA-200. Bearish regime marker.

Positive/Negative Directional Indicators. +DI > −DI = buyers in control.

Exponential Moving Average. Recent bars weighted more. Faster than SMA of same length.

Two-bar candlestick reversal where today's body fully engulfs yesterday's.

Hosoda 1969. Five lines (Tenkan 9, Kijun 26, Senkou A/B, Chikou) forming a cloud (kumo). Above cloud = bullish regime. Surfaced as LLM data, not a vote.

Squeeze (Bollinger)

Stochastic
Lane 1950s. %K = today's close in recent high-low range; %D = smoothed. >80 overbought, <20 oversold.

Highest/lowest over last 30 bars (standard preset). Most recent actionable S/R.
Synthesizer
LLM that takes technical view + news assessment + horizon and writes final Prediction.
