Quality controls — the four guardrail tiers

The synthesizer is an LLM, and an LLM will occasionally produce predictions that are wrong in mechanical ways: levels in the wrong order, signals it didn't actually see, RR violations, miscalibrated confidence. The guardrail layer catches these deterministically after synthesis but before persistence.

How the pipeline works

  • Four tiers run in order. The first failing tier short-circuits the rest.
  • If any tier fails, the synthesizer is invoked once more with the failure messages appended ("Your previous attempt failed these checks: […]. Fix them.").
  • If the retry also fails, the whole prediction call for that horizon raises a hard error. No "partial / half-correct" predictions ever ship.
  • We don't re-run the gather phase on retry — the technical view and news assessment haven't changed.

Tier 1 — Grounding

Question: "Are the prediction's basic numbers internally consistent with their inputs?"

CheckRule
Close-price echo The close the prediction quotes must equal the technical-view close to within 0.01%. Catches the LLM hallucinating a different "current price".
Bars-used echo The number of bars the prediction says it analysed must equal what was actually delivered. Catches under-reporting.
Entry-zone width sanity Width must be ≤ 0.5 × ATR. Catches "I emitted a zone that's actually a 5% range" — which would make worst-fill RR meaningless.
Entry-zone touches close The current close must lie within [zone_low − 0.10 ATR, zone_high + 0.10 ATR]. Catches the LLM placing the band far from current price.
Direction-level sanity BULLISH: target > zone_high AND stop < zone_high.
BEARISH: target < zone_low AND stop > zone_low.
ATR-distance sanity for stop Stop distance must be between 0.5 × ATR and 3.0 × ATR. Too tight → noise will trigger it; too far → RR can't possibly be met.
NEUTRAL claims neutrality If direction is NEUTRAL, computed RR must equal exactly 1.0 by convention.

Tier 2 — Citation

Question: "Did the LLM cite signals it actually saw — or did it make them up?"

Vocabulary construction

Before checking, we build the allowed vocabulary for this prediction by concatenating:

  • Every signal string from each cluster classifier.
  • Every candlestick pattern name (e.g. "hammer", "bullish_engulfing").
  • Every chart pattern name (e.g. "head_and_shoulders", "ascending_triangle").
  • Every catalyst's title and source URL from the news assessment.
  • Every risk's title and source URL.
  • Standard indicator names ("RSI", "MACD", "ADX", "ATR", "BB", "%B", "OBV", "SMA", "EMA", "+DI", "−DI", "%K", "%D").

Checks

CheckRule
Rationale token grounding At least 80% of meaningful tokens in the rationale must appear in the allowed vocabulary. Catches "Fibonacci retracement" when no Fibonacci tool ran.
contributing_signals match Each entry must either substring-match a vocabulary phrase, OR have ≥70% of its non-stop-word tokens in the vocabulary. Catches "strong dividend history" (a fundamental, not in our outputs).
conflicting_signals match Same rule, symmetric.
Catalyst URL anchoring Any URL in the rationale or signals must match a URL in the news assessment's catalysts or risks. Catches hallucinated sources.
Forbidden vocabulary The rationale must contain none of: guarantee, certain, definitely, risk-free, easy money, multibagger.

Tier 3 — Consistency

Question: "Does the prediction internally hang together?"

CheckRule
Direction ↔ rationale agreement The rationale must contain a keyword consistent with the declared direction. BULLISH rationale must mention at least one of: up, rise, rally, breakout, buy, long, support holding, momentum positive, trend up. Mirror set for BEARISH and NEUTRAL.
Confidence ↔ disagreement consistency If there are more conflicting signals than contributing signals, confidence must be ≤ 0.55. Catches "high-conviction" calls that enumerate more conflicts than supports.
Confidence ↔ news magnitude If news magnitude is HIGH AND news confidence ≥ 0.70 AND the synthesizer's direction agrees with the news direction, synthesizer confidence must be ≥ 0.55. Can't claim to have ignored a clear signal that aligned with the call.
NEUTRAL when sharply split If 2+ clusters are bullish AND 2+ are bearish, AND news direction disagrees with the synthesizer's call, the synthesizer must emit NEUTRAL.
NEUTRAL claims no edge NEUTRAL predictions cannot use the words buy / sell / long / short in rationale or contributing_signals.

Tier 4 — Calibration

Question: "Is the confidence number reasonable given the prediction's structure?"

CheckRule
Horizon ceiling confidence ≤ the horizon's ceiling: 0.90 daily, 0.85 weekly, 0.80 biweekly, 0.75 monthly.
Risk-reward floor risk_reward ≥ 1.5 for BULLISH/BEARISH. NEUTRAL bypasses (RR = 1.0 by convention).
NEUTRAL confidence ceiling NEUTRAL → confidence ≤ 0.65. Claiming high confidence in "no edge" is a contradiction.
Fallback-target confidence reduction If the rationale mentions "ATR projection" (i.e. the no-level fallback was used), confidence must be ≤ 0.70.
News-bounded confidence on short horizons DAILY: synthesizer confidence ≤ news_confidence + 0.10.
WEEKLY: ≤ news_confidence + 0.15.
Catches "I'm 0.85 sure on a daily call when news layer was 0.30 sure".
Degraded news cap If news_impact:degraded is in the model chain, confidence must be ≤ 0.65.

Why one retry, not many

Empirically, when the first attempt violates a guardrail, the second attempt with the failure message in the prompt usually succeeds. Beyond one retry we've seen diminishing returns and a tendency for the LLM to play whack-a-mole with the rules rather than re-think the prediction. One retry is the cost-vs-quality sweet spot.
